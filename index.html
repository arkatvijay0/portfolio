FEATURED · M.TECH RESEARCH PROJECT

Self-Validating EDA Agent

A research-driven web application that turns uploaded datasets and natural-language analysis questions into verified exploratory data analysis. The modular agent profiles data, plans and executes analysis steps, checks code and results, maps insights to supporting evidence, and generates structured reports. It uses Ollama for optional local language-model assistance and Isolation Forest for anomaly detection.

What it does
  • Accepts CSV, Excel and JSON datasets for automated EDA.
  • Plans and executes analysis with validation and retry-based correction.
  • Checks statistical results, generated claims and evidence mapping.
  • Produces evidence-grounded insights and a final analysis report.
